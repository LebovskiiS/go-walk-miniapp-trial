# go-walk-miniapp-trial

Статика прототипа «Кабинет ситтера» (Telegram Mini App) — проба, раздаётся через GitHub Pages.

Исходники и история правок живут в основном репозитории проекта (каталог `miniapp/`);
сюда они копируются как есть. Секретов здесь нет: только адрес публичного API.
Страница работает только внутри Telegram — вход идёт по подписи `initData`.
